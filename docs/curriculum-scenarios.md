# 커리큘럼 생성 시나리오 및 대비책

## 개요

사용자가 인강 커리큘럼을 생성할 때 입력할 수 있는 모든 변수와 시나리오를 분석하고,
각 시나리오에서 좋은 커리큘럼을 생성하기 위한 전략을 정리합니다.

---

## 사용자 입력 변수

| 변수 | 타입 | 범위 | 기본값 |
|------|------|------|--------|
| `targetDate` | string | 오늘 이후 날짜 | 없음 (필수) |
| `subjectHours` | Record<string, number \| null> | 0~20시간 (0.5 단위) | 모두 null |
| `subjectRatio` | Record<string, number> | 0~100% (5% 단위) | 수학35/영어25/국어20/... |
| `subjectDays` | Record<string, number[]> | 0(일)~6(토) 배열 | 모든 요일 [0,1,2,3,4,5,6] |
| `dailyStudyHours` | number | 8~14시간 | 프로필에서 로드 (기본 8) |
| `selectedCourses` | SelectedCourse[] | 0~N개 | 빈 배열 |
| `startFromChapter` | number | 0 ~ (강의수-1) | undefined (처음부터) |

## 시나리오 카테고리

### A. 시간 관련 시나리오

#### A1. 강의 총량 > 가용 시간 (시간 부족)

**상황**: 선택한 강좌의 총 학습량이 목표일까지의 가용 시간보다 많음

**예시**:
- 목표일: 30일 후
- 선택 강좌: 수학 100강 (50시간), 영어 60강 (30시간)
- 일일 순공시간: 8시간
- 가용 시간: 30일 × 8시간 × 0.8(버퍼) = 192시간
- 필요 시간: 80시간 + 자습 = 약 160시간 (인강만)

**현재 처리 방식**:
```
1. 인강 시간 제한 (MAX_LECTURE_RATIO: 60% 단일, 45% 복수)
2. 일별 초과 시 마지막 날에 몰아넣기
3. 프리뷰에서 경고 표시 + 시간 조정 슬라이더 제공
```

**개선 대비책**:
```
□ 생성 전 사전 계산하여 경고 표시
□ "목표일 연장 추천" 기능 추가
□ 강좌 자동 필터링 (우선순위 낮은 강좌 제외 추천)
□ 압축 모드: 복습 시간 줄이기, 1.5배속 가정
```

---

#### A2. 강의 총량 < 가용 시간 (시간 여유)

**상황**: 목표일까지 충분한 시간이 있어 강의가 일찍 끝남

**예시**:
- 목표일: 40일
- 영어 강좌: 20강 + 10강 = 30강
- 요일 설정: 월~토 (주 6일)
- 가용일: 약 34일
- 결과: 30강을 34일에 배분

**현재 처리 방식** ✅ (방금 구현):
```typescript
// spreadFactor 계산
const spreadFactor = lectureCount / availableDays; // 30/34 ≈ 0.88

// 분산 배치: 매일 배치하지 않고 균등 분산
if (spreadFactor < 1) {
  // 예상 배치 수 vs 실제 배치 수 비교하여 스킵
}
```

**추가 대비책**:
```
□ 여유 시간을 복습/자습 강화에 활용
□ "휴식일 자동 배정" 옵션 추가
□ 사용자에게 "여유 일정입니다" 시각적 표시
□ 심화 학습 추천 (기출 문제, 모의고사 등)
```

---

#### A3. 목표일이 매우 가까움 (< 7일)

**상황**: 목표일까지 일주일 미만

**예시**:
- 목표일: 3일 후
- 선택 강좌: 수학 20강

**대비책**:
```
□ 경고 메시지: "목표일이 너무 가깝습니다"
□ 핵심 강의만 선별 추천
□ 복습 제외 옵션 자동 활성화
□ 최소 목표일 제한 (예: 3일 이상)
```

---

#### A4. 목표일이 매우 멀음 (> 365일)

**상황**: 1년 이상의 장기 계획

**대비책**:
```
□ 단계별 마일스톤 설정 권유
□ 중간 점검 일정 자동 생성
□ 월별/분기별 분할 생성 옵션
□ "먼 목표입니다. 중간 목표를 설정하세요" 안내
```

### B. 과목 설정 시나리오

#### B1. 단일 과목만 시간 입력

**상황**: 수학만 3시간 입력, 나머지 과목 미입력

**현재 처리 방식**:
```typescript
// null이 아닌 과목만 커리큘럼에 포함
if (hours !== null && hours !== undefined && hours > 0) {
  subjectDailyMinutes[subject] = mins;
}
```

**대비책**:
```
✅ 현재: 해당 과목만 커리큘럼 생성
□ 추가: "다른 과목은 추가하지 않으시겠어요?" 확인
□ 추가: 과목 미입력 시 비중 모드 자동 전환 제안
```

---

#### B2. 과목 시간은 입력했지만 해당 과목 강좌 미선택

**상황**:
- 국어 2시간, 수학 3시간 입력
- 강좌는 수학만 선택

**대비책**:
```
□ 경고: "국어 강좌가 선택되지 않아 2시간이 제외됩니다"
□ skippedSubjects 배열에 추가하여 프리뷰에 표시
□ 해당 과목 강좌 검색 바로가기 제공
```

---

#### B3. 비중 모드에서 합계 ≠ 100%

**상황**: 과목 비중 합계가 100%가 아님

**현재 처리 방식**:
```tsx
const isValidRatio = totalRatio === 100;
// 100%가 아니면 "다음" 버튼 비활성화
```

**대비책**:
```
✅ 현재: 버튼 비활성화 + 경고 메시지
□ 추가: 자동 조정 버튼 ("나머지 과목에 균등 배분")
□ 추가: 실시간 부족/초과 표시 (현재 85%, 15% 더 필요)
```

---

#### B4. 모든 과목 0시간 또는 0%

**상황**: 모든 과목에 학습 시간을 배정하지 않음

**현재 처리 방식**:
```tsx
const hasAtLeastOneSubject = Object.values(props.subjectHours).some(h => h !== null && h > 0);
// 하나도 없으면 "다음" 버튼 비활성화
```

**대비책**:
```
✅ 현재: "최소 1개 과목 시간을 입력해주세요" 표시
□ 추가: 기본 설정 불러오기 버튼
□ 추가: 인기 설정 템플릿 제공
```

- 가용일: 34일

**현재 처리 방식** ✅:

**결과**: 30강이 34일에 걸쳐 균등 분산 (약 4일은 휴식)

## 테스트 체크리스트

### 기본 기능
- [ ] 단일 과목 + 단일 강좌
- [ ] 단일 과목 + 복수 강좌
- [ ] 복수 과목 + 각 1개 강좌
- [ ] 복수 과목 + 각 복수 강좌

### 시간 설정
- [ ] 시간 모드 (subjectHours)
- [ ] 비중 모드 (subjectRatio)
- [ ] 혼합 (일부 과목만 입력)

### 요일 설정
- [ ] 모든 요일 선택
- [ ] 주중만 (월~금)
- [ ] 주말만 (토, 일)
- [ ] 과목별 다른 요일

### 시간 조합
- [ ] 시간 여유 상황
- [ ] 시간 부족 상황
- [ ] 딱 맞는 상황

### 이어듣기
- [ ] 처음부터
- [ ] 중간부터
- [ ] 거의 끝에서부터

### 기존 플랜 연동
- [ ] 기존 플랜 없음
- [ ] 기존 플랜 1개
- [ ] 기존 플랜 여러 개
